One status update from a lost sock: the dryer didn't eat it — it filed for divorce, and the lint trap has the papers. Pure Python stdlib; it writes the line to `entry.txt`.

> Status update: the dryer didn't eat me. I filed for divorce. The lint trap has the papers.

## Why this line

- **A real joke with a turn:** the setup sounds like the classic "dryer ate me" story, then the sock undercuts it — it wasn't eaten, it left.
- **The missing partner, twisted:** the lost partner isn't a tragedy, it's a divorce, and the lint trap is holding the papers.
- **Sounds like a sock:** small, domestic, anxious about the dryer — dryer, lint trap, divorce papers, all household scale.
- **Punchline in the last few words:** "The lint trap has the papers" lands the joke at the very end.
- **Reads like a real status update:** short, self-contained, complete on its own with no follow-up needed.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`): 90 characters, one line, no trailing newline.
